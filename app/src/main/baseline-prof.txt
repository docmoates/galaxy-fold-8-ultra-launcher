# Hand-written baseline profile for FoldOS (HSPL / class-rule text format, wildcards as understood by AGP's
# profgen; R8 rewrites the names after minification). Packaged by AGP as assets/dexopt/baseline.prof and
# installed by androidx.profileinstaller on first launch, so the cold start path is AOT-compiled.
#
# Flags: H = hot (compile), S = startup (needed before the first frame), P = post startup,
# L = the class descriptor / method signature that follows. A bare "L<class>;" line preloads the class.
# Wildcards: "**" matches across package separators, "->**(**)**" means every method.
#
# Regenerate with a Macrobenchmark BaselineProfileRule once a benchmark module exists; until then this
# list follows the startup path: Application -> graph -> MainActivity -> LauncherViewModel ->
# LauncherRoot -> HomeScreen -> dock -> first widgets.
